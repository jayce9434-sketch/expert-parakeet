BUGBREAK: COLONY SIEGE — UPDATE 6.0 ART & AUDIO REBUILD
========================================================

This build is the solo rebuild made from the supplied v5.5 shell and assets.

WHAT CHANGED
- Multiplayer is removed from the shipped build. There is no multiplayer screen, PeerJS, network.js, room-code flow, host/guest state, WebRTC code, or multiplayer dependency.
- 9 playable insects: Ant, Termite, Ladybug, Fly, Mosquito, Dragonfly, Bee, Stinkbug, Spider.
- Bee, Stinkbug and Spider are the 3 new playable insects and are available immediately.
- Spider is the apex late-game pick: highest base damage, highest crit, strong movement, and Web Execution.
- 18 regular enemy species, up from the old small roster.
- 10 boss fights across 50 waves.
- Each boss has its own original looping boss music file: boss-1.mp3 through boss-10.mp3.
- 4 supplied normal music tracks remain as rotating biome music.
- New layered SFX for bite, hit, dash, gem, repair, level-up, boss arrival, special ability and death.
- Rebuilt app icon, menu, HUD, player art, enemy art, boss art, world rendering and upgrade presentation.
- 5 visual biomes: Clover Meadow, Flower Bed, Night Garden, Compost Yard, Porch Raid.
- Permanent upgrades, run mutations, boss relics, contracts, combo system, daily forage reward, gems, crumbs, nest repair and mobile controls.

18 REGULAR ENEMIES
Garden Ant, Fire Ant, Flea, Spider Mite, Earwig, Rove Beetle, House Centipede, Paper Wasp, Robber Fly, Wolf Spider, Assassin Bug, Bombardier Beetle, Hornet, Mantis Nymph, Giant Water Bug, Scorpion, Stag Beetle, Hunter Dragonfly.

CONTROLS
WASD / Arrow Keys = Move
Space = Bite
Shift = Dash
E = Special ability
R = Repair nest while close to it
Escape = Pause
Touch/iPad = joystick + Bite / Dash / Special / Repair buttons

GITHUB PAGES
1. Make a GitHub repository.
2. Upload every file from this ZIP directly into the repository root.
3. Do not create folders; this build is intentionally flat.
4. Settings -> Pages -> Deploy from branch -> main -> /(root).
5. Open the Pages link.

The app is installable as a PWA from a browser that supports Add to Home Screen.
